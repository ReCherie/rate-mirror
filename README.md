# 利率照妖镜 · Rate Mirror

输入一笔分期账单，算出被「月费率 0.6%」话术藏起来的**真实年化（IRR）**，并给出司法红线判定、提前还款决策与法条依据。

> **架构主张**：LLM 负责读懂混乱的人类账单，确定性代码负责算数。
> 准确性靠分层，可信度靠验证。

## 运行

```bash
pip install -r requirements.txt          # 首次
python3 web/server.py                    # 启动服务
```

打开 http://localhost:8600

- **手动测算 / 10 份样本账单**：不依赖网络与 API，前端本地计算；
- **识别账单**（右侧按钮）：粘贴账单文本，由 DeepSeek Function Calling 抽取字段，需配置 `DEEPSEEK_API_KEY`。

```bash
export DEEPSEEK_API_KEY=sk-xxxx          # 仅"识别账单"需要
```

## 结构

```
rate-mirror/
├── web/
│   ├── index.html     界面（无框架，含 IRR 计算）
│   └── server.py      静态服务 + POST /api/parse
├── core/
│   ├── irr.py         牛顿迭代 + 二分兜底
│   ├── parse.py       Function Calling 抽取 + 输出归一化
│   ├── report.py      红线判定 / 提前还款 / 换算
│   └── rag.py         法条检索
├── data/
│   ├── laws/          法条整理（引用前请核对原文）
│   └── sample_bills/  10 份样本 + 标准答案
├── scripts/           样本与期望值生成
├── tests/             11 项单元测试
└── prompts/           Prompt 迭代与实测记录
```
